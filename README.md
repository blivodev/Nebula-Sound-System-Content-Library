# Nebula Sound System — Content Library

Factory presets, drum kits, one-shots, loops, impulse responses, wavetables and demo projects for [Nebula Sound System](https://github.com/blivodev-commits/Nebula-Sound-System).

**Status: placeholder.** Content arrives with Phase 9 (built-in devices).

## Rules
- Only sounds we synthesise or render ourselves, or **CC0** (public domain) material from others.
- Our own content is released under **CC0-1.0**.
- Every asset is listed in `CONTENT_LICENSES.md` with its source and licence.
- Everything is editable and can be saved as a user preset.
